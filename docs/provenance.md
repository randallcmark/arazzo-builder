# Implementation provenance

## Clean-room boundary

The public `connEthics/arazzo-demo` product was used only to identify high-level
capabilities: workflow documentation, flow diagrams, sequence diagrams, YAML
editing, and visual workflow authoring.

No source code, styles, copy, fixtures, or tests from that proprietary
application are included in this repository.

The colour and shape direction is independently informed by Deel's public 2025
brand-refresh article: optimistic blue, purple, and yellow; rounded product
surfaces; and chunky abstract forms. No Deel logo, Bagoss font, illustration,
product screenshot, or other Deel-owned asset is included. Arazzo Loom retains
its own name, weave mark, layouts, components, and generated social artwork.

## Sources used to implement behavior

- The published OpenAPI Arazzo Specification
- The published OpenAPI Specification
- Public documentation for the independently licensed packages listed in
  `THIRD_PARTY_NOTICES.md`

## Repository-owned implementation

Parsing coordination, structural diagnostics, YAML-preserving workflow and
source insertion, the visual workflow composer, visual design, local draft
lifecycle, and export behavior were written for this repository.
