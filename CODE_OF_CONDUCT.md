# Code of conduct

This project welcomes constructive participation regardless of experience,
identity, background, or ability.

Contributors are expected to:

- discuss ideas and disagreements respectfully;
- give actionable feedback about the work rather than the person;
- avoid harassment, discrimination, threats, and publication of private
  information;
- respect project scope, licensing, provenance, and security boundaries.

Project maintainers may edit or remove contributions and participation that do
not meet these expectations. Serious or sensitive concerns should be reported
through GitHub Private Vulnerability Reporting when they involve security, or
privately to the repository owner through their GitHub profile for other
conduct matters.

Maintainers should handle reports discreetly, consistently, and without
retaliation.
